Important Notice: This application is developed exclusively for educational, research, and technical learning purposes. It is not intended for production use, commercial deployment, or access by any individual other than its sole developer. No end-user services are offered through this application.

1. Nature and Purpose of This Application

TestConnector ("the Application") is a non-commercial, non-production software prototype developed solely for the purpose of learning, academic research, and technical experimentation with the Meta Marketing API. The Application is intended to be used exclusively by its developer as part of a hands-on technical study of API integration patterns and connector development methodology.

The Application is not offered as a service to the public, is not distributed to any third party, and shall not be used for any commercial, advertising, or revenue-generating purpose of any kind. No business operations, transactions, or legal obligations are conducted through this Application.

2. Scope of Access

The Application accesses the Meta Marketing API for the sole purpose of exploring and validating API response structures, endpoint behaviours, and data schemas as part of a technical learning exercise. Access is limited to ad account data, campaign metadata, ad set configurations, ad creatives, and performance insights that belong exclusively to the developer's own test ad accounts.

At no point does the Application access, process, or store data belonging to any third-party individual, business, or advertiser.

3. Data Collection and Storage

The Application does not collect, record, store, transmit, or process any personally identifiable information (PII) from any person. All API responses retrieved during development sessions are transient in nature and are used solely for in-session technical inspection. No data is persisted to any database, file system, or external service.

4. Data Sharing and Disclosure

The Application does not share, sell, license, transfer, or otherwise disclose any data — including Meta API data — to any third party under any circumstances. There are no data processors, sub-processors, or downstream recipients of any data accessed through this Application.

5. Authentication and Credential Security

Access tokens and API credentials used to authenticate with the Meta Marketing API are managed as environment variables in accordance with secure software development practices. These credentials are never hardcoded in source code, committed to version control systems, logged, or shared with any party.

6. No End-User Interaction

This Application has no user interface accessible to the public and does not serve, solicit, or interact with any end users. It operates exclusively in a controlled developer environment. No registration, login, or account creation is offered to or required of any person other than the developer.

As this Application is developed purely for learning and technical experimentation, it is provided on an "as-is" basis without warranties of any kind, either express or implied. The developer assumes no liability arising from the use or inability to use this Application, nor from any data accessed through it during the development process.

8. Changes to This Policy

This Privacy Policy may be updated from time to time to reflect changes in the nature or scope of the Application's development activities. Any updates will be reflected by a revised "Last updated" date at the top of this document.

9. Contact
